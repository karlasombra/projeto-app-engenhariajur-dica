# Storyboard

## `propostas/`: versão atual

São 4 propostas de design para o **Será Golpe?**. Todas têm as mesmas funções e as mesmas 4 telas (Abertura → Início → Verificar → Resultado).

| Arquivo | Proposta |
|---|---|
| `proposta-A-clareza.png` | A: Clareza (acessível, letra grande, alto contraste) |
| `proposta-B-elegancia.png` | B: Elegância (escuro e dourado, estilo banco premium) |
| `proposta-C-conversa.png` | C: Conversa (chat com a assistente Clara) |
| `proposta-D-semaforo.png` | D: Semáforo (verde, amarelo e vermelho; colorido) |

- Os `.png` (3200×1800, 16:9) estão prontos para usar no slide.
- Os `.html` são a fonte editável. O `base.css` tem a estrutura comum.
- Para gerar as imagens de novo: `powershell -ExecutionPolicy Bypass -File propostas\gerar-imagens.ps1`
