# Será Golpe? — o app

App de demonstração (MVP) para a apresentação da AV2. Tudo é simulado.

## Abrir no computador

Dê dois cliques em `index.html`. Ele abre no navegador com cara de celular.
(Para testar o "instalar" e o funcionamento sem internet, ele precisa estar publicado, veja abaixo.)

## Publicar (GitHub Pages)

1. Envie a pasta para o GitHub (`git add .`, `git commit`, `git push`).
2. No GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**. O arquivo `.github/workflows/pages.yml` publica a pasta `app/` sozinho a cada push.
3. O endereço fica: `https://karlasombra.github.io/projeto-app-engenhariajur-dica/`

## Instalar no celular

- **Android (Chrome):** abra o endereço → menu ⋮ → **Adicionar à tela inicial / Instalar app**.
- **iPhone (Safari):** abra o endereço → botão Compartilhar → **Adicionar à Tela de Início**.

Abra o app uma vez com internet antes da apresentação. Depois ele funciona offline.

## Roteiro sugerido para a apresentação (3 a 4 min)

1. Abrir o app pelo ícone: semáforo acende → tela de senha. Mostrar o **A+** (letra maior). Entrar com a **digital**.
2. **Início:** alerta da semana, botão roxo de verificar e os cartões coloridos.
3. **Verificar → exemplo "Filho com número novo" → Será golpe?** → tela Analisando (passo 2) → **Sinal vermelho**. Tocar em **Ouvir**.
4. **Avisar minha família** → escolher Carlos e Ana → Aviso enviado.
5. Repetir com **"Recado da neta"** → **Sinal verde** (mostra que o app não acusa tudo).
6. **Caí em um golpe:** banco (MED), Delegacia Eletrônica, Disque 100 e **Seus direitos** (art. 171 do Código Penal). É a parte de Engenharia Jurídica.
7. Passar rápido por Aprender (tocar no play), Família e Perfil.

Dicas: senha = qualquer 4 números. Para "zerar" a demonstração, limpe os dados do site no navegador.
