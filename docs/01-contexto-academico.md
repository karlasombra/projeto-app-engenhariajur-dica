## Enunciado do projeto

Aplicar as etapas do Design Thinking (Empatizar → Definir → Idear → Prototipar → Testar) para criar um aplicativo, produzindo uma sequência de artefatos.
Original: [`referencias/AV2 Atividades em Equipe.pdf`](../referencias/AV2%20Atividades%20em%20Equipe.pdf).

O exemplo do professor é um app para ajudar idosos a se organizarem financeiramente. **O nosso é um app para ajudar idosos a reconhecer o estelionato digital.**
